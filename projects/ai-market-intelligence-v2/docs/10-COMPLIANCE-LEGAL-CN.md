# 中国合规合法实施方案（Compliance by Design · CN）

> **版本** v1.0 | **适用产品**：AI 市场情报平台 V2（合规 AI 选品研究）  
> **法律效力**：本文档为产品与工程实施指引，**不构成法律意见**；上线前建议法务/律师复核。

---

## 一、产品合法定位（对外口径）

| ❌ 禁止定位 | ✅ 合法定位 |
|------------|------------|
| 爬虫工具、数据采集器 | **AI 市场研究 / 趋势情报平台** |
| 商品数据库、爆品库 | **类目级市场洞察与决策建议** |
| 店铺监控、批量导出 | **用户自主研究助手 + 聚合分析** |
| 原始数据/API 转售 | **SaaS 情报订阅（非数据交易）** |

**一句话**：我们是 **「软件 + 算法 + AI 分析服务」**，不是 **「数据商品批发商」**。

## 三、数据采集层合规红线（L1～L2，内部）

### 3.1 绝对禁止

1. 绕过登录、验证码、签名、频率限制等**技术保护措施**
2. 违反目标平台 User Agreement / Robots 的**批量自动化抓取**
3. 为**对外销售原始数据**而采集
4. 采集**可识别特定自然人**的信息用于画像或转售（店主手机号、身份证等）
5. 采集、存储、传输**平台未公开**的数据

### 3.2 允许方向（须写入《用户服务协议》）

1. 用户在**自己设备上**浏览其有权访问的**公开页面**，用于**个人商业研究**
2. 内部系统将快照用于**统计、建模、趋势分析**，结果仅输出**聚合指标**
3. 遵守**最小必要**：只存分析所需字段，设**保留周期**（如 90～180 天滚动删除原始快照）
4. 优先探索**官方授权渠道**（平台开放能力、合规数据合作）作为长期方案

### 3.3 司法与监管趋势（2024～2025）

- **公开 ≠ 可随意商用**：已公开个人信息/数据的使用需在**合理范围**内（最高法参考案例 2025-07-2-369-003）
- **刑事打击**针对：破坏系统、突破防护、大规模窃取底层数据
- **民事/不正当竞争**针对：替代平台核心数据产品的「搭便车」分发

→ **V2 战略价值**：对外不交付可替代平台数据包的 zip/data.js，显著降低不正当竞争与数据交易风险。

## 四、对外产品合规设计（L4～L6）

### 4.1 输出白名单（仅允许）

- 类目 / 赛道 / 价格带 / 时间窗
- 增长率、竞争指数、蓝海指数等**自研指标**
- AI 归纳的趋势、建议、风险（**不可追溯到单商品/单店**）
- 聚合关键词云（**不含**完整标题库、商品链接）

### 4.2 输出黑名单（禁止）

- 商品 ID、SKU、商品 URL、主图 URL
- 店铺 ID、店铺名称、经营者可识别信息
- 可下载的 `data.js` / CSV 全量商品表
- 对外 API 按商品维度查询
- 用户间共享「监控名单」中的原始店铺明细（V2）

### 4.3 代码层强制（见 `services/compliance_gate.py`）

```
内部 raw 表 ──► 聚合引擎 ──► compliance_gate.sanitize() ──► AI ──► compliance_gate.audit_report() ──► 发布
```

任何对外 JSON/HTML 发布前必须经过 `ComplianceGate`，违规字段 **hard fail**。

## 五、生成式 AI 专项合规

依据《生成式人工智能服务管理暂行办法》：

| 要求 | 实施方案 |
|------|----------|
| 训练/推理数据合法来源 | 仅使用**自采公开统计结果**或**合法授权数据**；保留数据来源台账 |
| 内容安全 | 输出前 **敏感词 + 违法建议** 过滤；禁止侵权抄款、虚假宣传类建议 |
| 不得生成违法内容 | Prompt 约束 + 后置审核 + 人工抽检 |
| 标识 | 报告页脚：**「本内容由 AI 辅助生成，仅供研究参考」** |
| 算法备案 / 安全评估 | 若对**公众**提供且具舆论属性或社会动员能力，须按网信办要求评估与备案（**上线前法务确认**） |
| 用户投诉 | 会员中心提供「内容纠错 / 投诉」入口，15 日处理机制 |

### 5.1 AI 输入规范（强制）

```json
{
  "category": "小学教辅",
  "growth_rate_pct": 42,
  "competition_index": 18,
  "price_band": "9-19",
  "trend_label": "连续上涨"
}
```

**禁止**向 LLM 传入：商品名、店铺名、ID、URL、图片。

## 六、用户协议与告知（必须文档化）

上线 V2 前须准备（可放 `docs/legal/` 模板）：

1. **《用户服务协议》** — 研究工具定位、禁止用途、责任限制
2. **《隐私政策》** — 收集项、目的、保留期、用户权利
3. **《AI 生成内容说明》** — 局限性、非投资建议
4. **《免责声明》** — 嵌入每份情报报告（已有 V1 disclaimer 可升级）
5. **禁止用途条款**：转售数据、侵权抄款、刷量、爬取他人隐私

## 七、数据安全与等级保护思路

| 措施 | 说明 |
|------|------|
| 分类分级 | `raw_*` 内部机密；`insight_*` 对外可发布 |
| 访问控制 | 内部表 **无** 会员 API；RBAC + 审计日志 |
| 传输 | 全站 HTTPS；JWT + 设备绑定（现网已有） |
| 存储 | PG 加密磁盘；备份加密；`.env` 不入 git |
| 日志 | 访问日志 6 个月+；**日志脱敏**（不记完整标题） |
| 应急 | 泄露预案、72h 通知流程（PIPL 要求） |
| 出境 | 若 LLM 调用境外 API，须评估是否构成数据出境（法务） |

## 八、双轨期（V1 Legacy）合规过渡

| 阶段 | V1 Legacy | V2 |
|------|-----------|-----|
| 新用户 | 停售 | 只售情报 |
| 在期老用户 | 履约至到期，协议已披露 | 可选升级 |
| 对外宣传 | 不再主推「数据包」 | 主推 AI 情报 |
| 下线 | 到期后关闭 zip 下载 | — |

**过渡原则**：不断服、不虚假宣传、新签合规化。
