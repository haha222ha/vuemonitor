# V1 与 V2 输出对比

> 供大模型与团队快速理解「什么必须消失、什么可以保留」。

## 一句话

| 版本 | 用户买到的是什么 |
|------|------------------|
| **V1** | 可离线打开的**商品级数据包**（data.js + HTML 表格） |
| **V2** | **类目级 AI 市场情报**（指标 + 建议 + 风险，无可定位实体） |

## 交付物对比

| 维度 | V1 Legacy | V2 Intelligence |
|------|-----------|-----------------|
| 文件形态 | zip（含 data.js） | 在线 HTML / PDF 摘要 |
| 数据粒度 | 单商品行（28 列） | 类目 × 价格带 × 时间窗 |
| 商品 ID | ✅ 有 | ❌ 禁止 |
| 店铺名 | ✅ 有 | ❌ 禁止 |
| 销量原值 | ✅ 有 | ❌ 禁止（仅增长率等） |
| AI 文案 | ❌ 无 / 弱 | ✅ 核心 |
| 自研指数 | 部分派生字段 | ✅ 完整指数体系 |
| 可下载原始表 | ✅ 可以 | ❌ 禁止 |
| 合规定位 | 数据报告 | 情报 / 研究 |

## 字段映射（内部保留 → 对外输出）

| V1 内部字段 | V2 对外等价物 |
|-------------|---------------|
| `sold`, `v1d`, `actual_v1d` | `growth_rate_pct`, `trend_label` |
| `title`, `goods_id` | **不输出**（仅内部聚类） |
| `store_name`, `store_id` | **不输出** → `competition_index` |
| `price` | `price_band`（如 9-19） |
| `gr`, `vsr`, `burst` | 并入 `heat_score` / `blue_ocean_score` |
| `top_keywords` | ✅ 保留为类目关键词云（无商品绑定） |
| `top_stores` | ❌ 删除 → 改为「竞争密度指数」 |

## 会员页变化（Phase 4 才动现网）

| V1 会员中心 | V2 会员中心 |
|-------------|-------------|
| 报告库 → 下载 zip | 情报库 → 在线阅读 |
| 表格 GR / Vue 列表 | 6 页情报报告 |
| 批量打包下载 | PDF 摘要下载（可选） |

## 在期买家（Phase 3 之前）

- 已购 V1 周期内：**继续** zip 下载，不改体验
- 新购：**只卖 V2** 情报 SKU
- 代码：**双轨** `archive_type=member_daily_zip`（Legacy）与 `insight_daily_html`（V2，新类型，Phase 2+ 设计）
