# 架构定稿（摘要）

完整说明见 [需求规格书_xhs-cloud_v1.md](./需求规格书_xhs-cloud_v1.md)。

## 一句话

**PG `xhs_monitor` 是选品运行库**；本地 SQLite 13GB **不上云**，仅一次性导出「报告日增>0 商品」的 **sold_history 日照**。

## 三库分工

| 对象 | 角色 |
|------|------|
| 本地 SQLite | 历史采集遗留，同步完成后不参与日常 |
| PG `public` | vuemonitor 现网 |
| PG `xhs_monitor` | 选品监控池 + 日照 + 报告 + 会员 zip 索引 |

## 集成

```
gen_report（不动）→ data.js
    → cloud_sync_client / scp
    → xhs-cloud API + PG
vuemonitor :8000（不动）
```
