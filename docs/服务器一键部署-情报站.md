# intel.xhs365.cn 服务器一键部署

> **服务器 IP**：`47.239.181.111`（域名 `intel.xhs365.cn` 指向同一台）  
> **本地自动化**：每天 08:00 / 20:00 执行 `AI互联网信息量化\remote_sync\scheduled_sync.ps1`，把数据库与 HTML 报告推到线上 API。  
> **有前端/后端代码更新时**：只需在服务器 SSH 里粘贴下面**一条**命令（含拉代码、构建、Nginx、迁移、健康检查、报告静态自检）。

---

## 唯一命令（整段复制粘贴）

```bash
cd /opt/vuemonitor && git fetch origin && git reset --hard origin/main && if [ -f config/intel_production.json ]; then SHOP_URL=$(python3 -c "import json; print(json.load(open('config/intel_production.json'))['xhs_shop_url'])"); printf 'VITE_API_BASE_URL=/api/v1\nVITE_XHS_SHOP_URL=%s\n' "$SHOP_URL" > web-intel/.env.production; fi && cd web-intel && npm install --silent 2>/dev/null; npm run build && cd .. && (sudo cp nginx/intel.conf /etc/nginx/conf.d/intel.conf 2>/dev/null || sudo cp nginx/intel.conf /etc/nginx/sites-available/intel.conf) && cd server && (source .venv/bin/activate 2>/dev/null || source venv/bin/activate 2>/dev/null; alembic upgrade head 2>/dev/null; true) && cd .. && sudo systemctl restart vuemonitor && sudo nginx -t && sudo nginx -s reload && sleep 3 && curl -s http://127.0.0.1:8000/health | python3 -m json.tool && SAMPLE=$(ls server/static/reports/weekly_*.html 2>/dev/null | head -1); if [ -n "$SAMPLE" ]; then FN=$(basename "$SAMPLE"); curl -sI "http://127.0.0.1/static/reports/$FN" | head -n1; else echo "WARN: no weekly_*.html in static/reports yet"; fi && echo "OK: https://intel.xhs365.cn — 浏览器 Ctrl+F5 强刷"
```

也可直接执行仓库脚本（内容与上面等价）：

```bash
bash /opt/vuemonitor/scripts/server-deploy-intel.sh
```

## 本地（一般不用你动手）

| 方式 | 说明 |
|------|------|
| 计划任务 | 每天 **08:00**、**20:00** 自动 `full_sync.py --scheduled` |
| 立即同步 | 双击 `D:\vuemonitor\AI互联网信息量化\remote_sync\scheduled_sync.ps1` |
| 同步目标 | `https://intel.xhs365.cn` → 服务器 `47.239.181.111` |

本地同步**不会**替你在服务器上 `git pull` / `npm build`；代码变更仍需上面服务器一条命令。

---

## 部署后自检

1. 打开 https://intel.xhs365.cn ，**Ctrl+F5** 强刷  
2. **决策报告**：应分「周度 / 月度 / 选题深度」区块，不再混排  
3. 点「查看报告」应显示 HTML，而非首页  
4. **风险预警**：有「淘汰赛道 / 监测预警」Tab，无测试脏数据

## 连通性（本机可测，无需 SSH）

```powershell
curl.exe -s https://intel.xhs365.cn/api/v1/health
curl.exe -s http://47.239.181.111:8000/health
```

SSH（`root@47.239.181.111`）需你在阿里云控制台配置密钥；未配置时只能用上面 HTTP 自检。
