## 一、紧急Bug修复

### 1.1 Electron 单实例锁（P0 - 必须修复）

**问题**：点击桌面图标会打开新窗口，而不是恢复已最小化到托盘的程序。用户可以同时开3个窗口。

**当前代码**：`client/src/main/index.ts` 没有调用 `app.requestSingleInstanceLock()`

**修复方案**：
```typescript
// client/src/main/index.ts - bootstrap() 最前面
const gotTheLock = app.requestSingleInstanceLock();
if (!gotTheLock) {
  app.quit();
  return;
}

app.on('second-instance', () => {
  // 恢复主窗口而不是开新窗口
  const win = windowManager?.getMainWindow();
  if (win) {
    if (win.isMinimized()) win.restore();
    win.show();
    win.focus();
  }
});
```

**是否需要改服务端**：否

## 二、商品管理增强

### 2.1 Excel 批量导入商品ID（P0）

**参考**：`小红书数据监控软件2.2(修复版)/lib/simple-excel-uploader.js`

**功能描述**：
- 在"我的商品"页面添加"批量导入"按钮
- 提供 Excel 模板下载（包含：商品ID、商品名称、分类 等字段）
- 用户上传 Excel 后解析并批量添加到监控列表
- 显示导入预览：成功X条、失败X条、重复X条
- 支持拖拽上传

**UI 设计**：
```
┌─────────────────────────────────────────┐
│  批量导入商品                             │
│                                          │
│  📥 拖拽Excel文件到此处，或点击选择文件     │
│                                          │
│  支持格式：.xlsx .xls                     │
│  📥 下载导入模板                          │
│                                          │
│  导入预览：                               │
│  ✅ 可导入 15 条  ❌ 失败 2 条  ⚠️ 重复 3条│
│                                          │
│  [取消]                    [确认导入]      │
└─────────────────────────────────────────┘
```

**是否需要改服务端**：是 — 需要新增 `POST /api/v1/products/batch-import` 接口

## 三、采集功能增强

### 3.1 实时采集进度面板（P0）

**参考**：`小红书数据监控软件2.2(修复版)` 的批量监控进度对话框

**当前问题**：点击"立即采集"后看不到进度，不知道哪些在采、哪些完成、哪些失败。

**功能描述**：
- 采集任务提交后，显示实时进度面板
- 总进度条：已完成 X / 总共 Y
- 每个商品的采集状态：等待中 / 采集中 / 成功 / 失败
- 实时日志滚动显示
- 结果统计：成功数、失败数、跳过数
- 支持暂停/继续/停止采集
- 失败商品支持重试

**UI 设计**：
```
┌─────────────────────────────────────────┐
│  📊 采集进行中...                    ⏸ ⏹  │
│                                          │
│  总进度  ████████░░░░  15/23 (65%)       │

│  │ 15:32:01 ✅ 商品A 采集成功         │   │

│                                          │
│  [重试失败项]              [关闭]         │
└─────────────────────────────────────────┘
```

**是否需要改服务端**：是 — 需要 WebSocket 推送采集进度，或轮询接口

## 四、数据可视化增强

### 4.1 商品价格/销量趋势图（P0）

**参考**：`小红书数据监控软件2.2(修复版)/lib/simple-line-chart.js` + `time-series-data-manager.js`

**当前问题**：商品详情页没有变化曲线，看不到监控商品的价格和销量随时间的变化趋势。

**功能描述**：
- 商品详情页添加趋势图区域
- 价格趋势折线图：展示价格随时间变化
- 销量趋势折线图：展示销量随时间变化
- 评分趋势折线图
- 时间范围选择：7天 / 30天 / 90天
- 异常点标注（价格突变、销量暴增等用红色标记）
- 鼠标悬浮显示具体数值

**技术方案**：使用 ECharts 或 Chart.js

**是否需要改服务端**：是 — 需要时间序列数据接口 `GET /api/v1/products/:id/timeseries`

---

### 4.2 商品对比趋势图（P1）

**功能描述**：
- 对比页支持多商品趋势叠加图
- 选择2-5个商品，在同一图表中对比价格/销量走势
- 归一化显示（百分比变化）方便对比不同量级商品

**是否需要改服务端**：是 — 批量时间序列数据接口

---

### 4.3 Dashboard 数据概览增强（P2）

**参考**：`小红书数据监控软件2.2(修复版)` 的统计卡片

**功能描述**：
- 增加统计卡片：平均价格、总销量、异常商品数
- 每个卡片显示环比变化（比上周 +X% / -X%）
- 新增/删除商品趋势迷你图

**是否需要改服务端**：部分 — 需要聚合统计接口

## 五、异常监控增强

### 5.1 24小时增长计算（P1）

**参考**：`小红书数据监控软件2.2(修复版)/lib/simple-growth-calculator.js`

**功能描述**：
- 自动计算每个商品的24小时新增销量
- 自动计算24小时新增销售额（新增销量 × 商品价格）
- 在商品列表中显示增长数据
- 异常商品自动标记（销量暴增/暴跌）

**是否需要改服务端**：是 — 后端计算增长数据

---

### 5.2 异常检测增强（P2）

**参考**：`小红书数据监控软件2.2(修复版)/lib/simple-anomaly-detector.js` + `easy-anomaly-manager.js`

**功能描述**：
- 价格突变检测（24h涨跌幅超过阈值）
- 销量异常检测（24h销量偏离均值2个标准差）
- 评分异常检测
- 店铺粉销比异常（店铺销量÷粉丝数，判断刷单）
- 异常商品汇总视图，支持按分类筛选

**是否需要改服务端**：是 — 异常检测算法和接口
