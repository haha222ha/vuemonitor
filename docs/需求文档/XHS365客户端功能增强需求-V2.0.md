```python
# Response
```

**Electron IPC通道**：
```typescript
// client/src/main/preload.ts — 新增
"storage:batch-insert-products": true,

// client/src/main/ipc/handlers.ts — 新增
ipcMain.handle("storage:batch-insert-products", async (_event, products: Record<string, unknown>[]) => {
    const storage = getStorage();
    let imported = 0, duplicated = 0, failed = 0;
    const failedItems: {platform_product_id: string; reason: string}[] = [];
    for (const p of products) {
        try {
            const existing = storage.query(
                "SELECT id FROM products WHERE platform = ? AND platform_product_id = ? AND is_active = 1",
                [p.platform || "xhs", p.platform_product_id]
            );
            if (existing.length > 0) { duplicated++; continue; }
            storage.insertProduct(p as Record<string, unknown>);
            imported++;
        } catch (e) {
            failed++;
            failedItems.push({platform_product_id: String(p.platform_product_id), reason: String(e)});
        }
    }
    return { total: products.length, imported, duplicated, failed, failedItems };
});
```

```python
class ProductCategory(UUIDPrimaryKeyMixin, TimestampMixin, Base):
    __tablename__ = "product_categories"

    user_id: Mapped[uuid.UUID] = mapped_column(UUID(as_uuid=True), ForeignKey("users.id", ondelete="CASCADE"))
    name: Mapped[str] = mapped_column(String(50), nullable=False)
    icon: Mapped[str | None] = mapped_column(String(50))
    sort_order: Mapped[int] = mapped_column(SmallInteger, default=0)
    parent_id: Mapped[uuid.UUID | None] = mapped_column(UUID(as_uuid=True), ForeignKey("product_categories.id"))

    __table_args__ = (
        UniqueConstraint("user_id", "name", name="uq_user_category_name"),
        Index("idx_categories_user_id", "user_id"),
    )
```

## 六、商品发现数据库（P0 新增 · V2.1重设计）

### 6.0 功能概述与商业化定位

**核心定位**：基于自有百万级商品数据库（`xhs_burst_monitor_backup.db`），打造"发现→搜索→加入监控"的会员转化漏斗。

**商业化设计理念**（参考 Semrush / Ahrefs / 蝉妈妈 等SaaS标准）：

```
免费用户 ──→ 搜索可见但结果受限 ──→ "想看更多？升级Pro" ──→ 付费转化
   │                                      │
   └── 能搜索、能添加监控（3个商品上限）      └── Pro: 完整信息 + 更多配额
                                              └── Premium: 爆品洞察 + 无限搜索
```

**核心原则**：
1. **搜索即转化入口** — 免费用户可以搜索，但搜索结果只展示商品标题+店铺名称（截断），看不到价格/销量等关键数据
2. **只展示标题和店铺名** — 这是唯一展示的两个字段，其他字段按会员等级逐步解锁
3. **添加监控受套餐商品上限约束** — 免费用户3个、Pro 50个、Premium 500个
4. **只读查询** — 数据库仅提供搜索发现能力，不提供数据导出/下载
5. **频率限制** — 按套餐等级限制每日搜索次数，防止批量爬取
6. **审计日志** — 所有查询记录到 `FeatureGateUsage` 表

**数据资产概况**（`D:\小红书数据库\xhs_burst_monitor_backup.db`）：

### 6.2 架构设计 — 只读SQLite连接池

**关键决策**：服务端直接挂载 `xhs_burst_monitor_backup.db` 为只读SQLite数据库。

**理由**：
1. 100万条记录SQLite查询性能足够（<20ms，加索引后）
2. 只读模式天然防止数据被篡改
3. 数据更新时只需替换db文件，无需迁移
4. 不污染主业务PostgreSQL数据库

**服务端架构**：

```
server/
├── app/
│   ├── api/
│   │   └── discovery.py              ← 新增：商品发现API路由
│   ├── services/
│   │   └── discovery_db.py           ← 新增：只读SQLite连接池
│   └── middleware/
│       └── feature_gate.py           ← 修改：新增gate映射
├── data/
│   └── xhs_burst_monitor_backup.db   ← 部署：只读数据库文件
```

```python
# server/app/services/discovery_db.py
import aiosqlite
import os
import logging
from typing import Any

logger = logging.getLogger(__name__)


class DiscoveryDatabase:
    _instance: "DiscoveryDatabase | None" = None
    _db_path: str | None = None
    _connection: aiosqlite.Connection | None = None

    def __init__(self, db_path: str):
        self._db_path = db_path

    @classmethod
    def get_instance(cls) -> "DiscoveryDatabase | None":
        return cls._instance

    @classmethod
    def initialize(cls, db_path: str) -> "DiscoveryDatabase":
        if cls._instance is None:
            cls._instance = cls(db_path)
        return cls._instance

    async def connect(self) -> None:
        if self._connection is not None or not self._db_path or not os.path.exists(self._db_path):
            logger.warning(f"Discovery DB not found at {self._db_path}")
            return
        self._connection = await aiosqlite.connect(self._db_path)
        self._connection.row_factory = aiosqlite.Row
        await self._connection.execute("PRAGMA query_only = ON")
        await self._connection.execute("PRAGMA journal_mode = WAL")
        await self._connection.execute("PRAGMA cache_size = -64000")
        await self._connection.execute("PRAGMA temp_store = MEMORY")
        try:
            await self._connection.execute("""
                CREATE INDEX IF NOT EXISTS idx_backup_goods_keyword
                ON backup_goods(keyword)
            """)
            await self._connection.execute("""
                CREATE INDEX IF NOT EXISTS idx_backup_goods_store_id
                ON backup_goods(store_id)
            """)
            await self._connection.execute("""
                CREATE INDEX IF NOT EXISTS idx_backup_goods_sold_num
                ON backup_goods(sold_num DESC)
            """)
            await self._connection.commit()
        except Exception as e:
            logger.warning(f"Index creation skipped: {e}")
        logger.info(f"Discovery DB connected: {self._db_path}")

    async def close(self) -> None:
        if self._connection:
            await self._connection.close()
            self._connection = None

    async def reload(self) -> None:
        await self.close()
        await self.connect()

    async def search_goods(
        self,
        keyword: str,
        page: int = 1,
        page_size: int = 20,
        min_price: float | None = None,
        max_price: float | None = None,
        min_sold: int | None = None,
        store_id: str | None = None,
        sort_by: str = "sold_num",
        sort_order: str = "desc",
    ) -> dict[str, Any]:
        if not self._connection:
            return {"items": [], "total": 0}

        conditions = []
        params: list[Any] = []

        if keyword:
            conditions.append("(title LIKE ? OR keyword LIKE ? OR goods_id = ?)")
            params.extend([f"%{keyword}%", f"%{keyword}%", keyword])
        if min_price is not None:
            conditions.append("deal_price >= ?")
            params.append(min_price)
        if max_price is not None:
            conditions.append("deal_price <= ?")
            params.append(max_price)
        if min_sold is not None:
            conditions.append("sold_num >= ?")
            params.append(min_sold)
        if store_id:
            conditions.append("store_id = ?")
            params.append(store_id)

        where_clause = " AND ".join(conditions) if conditions else "1=1"

        allowed_sorts = {"sold_num", "deal_price", "shelf_time", "scan_count"}
        sort_col = sort_by if sort_by in allowed_sorts else "sold_num"
        sort_dir = "DESC" if sort_order.lower() == "desc" else "ASC"

        count_sql = f"SELECT COUNT(*) FROM backup_goods WHERE {where_clause}"
        async with self._connection.execute(count_sql, params) as cursor:
            total = (await cursor.fetchone())[0]

        offset = (page - 1) * page_size
        data_sql = f"""
            SELECT goods_id, title, deal_price, sold_num,
                   store_id, store_name, keyword,
                   shelf_time, filter_tag, scan_count,
                   first_seen, last_seen
            FROM backup_goods
            WHERE {where_clause}
            ORDER BY {sort_col} {sort_dir}
            LIMIT ? OFFSET ?
        """
        async with self._connection.execute(data_sql, params + [page_size, offset]) as cursor:
            rows = await cursor.fetchall()

        items = []
        for row in rows:
            items.append({
                "goods_id": row["goods_id"],
                "title": row["title"] or "",
                "deal_price": row["deal_price"],
                "sold_num": row["sold_num"],
                "store_id": row["store_id"],
                "store_name": row["store_name"] or "",
                "keyword": row["keyword"],
                "shelf_time": row["shelf_time"],
                "filter_tag": row["filter_tag"],
                "scan_count": row["scan_count"],
                "first_seen": row["first_seen"],
                "last_seen": row["last_seen"],
            })

        return {"items": items, "total": total, "page": page, "page_size": page_size}

    async def search_stores(
        self,
        keyword: str,
        page: int = 1,
        page_size: int = 20,
    ) -> dict[str, Any]:
        if not self._connection:
            return {"items": [], "total": 0}

        params = [f"%{keyword}%"]
        count_sql = """
            SELECT COUNT(*) FROM (
                SELECT store_id FROM backup_goods
                WHERE store_name LIKE ? AND store_id IS NOT NULL AND store_id != ''

        """

            rows = await cursor.fetchall()

        items = []
        for row in rows:
            items.append({
                "store_id": row["store_id"],
                "store_name": row["store_name"],
                "product_count": row["product_count"],
                "avg_price": round(row["avg_price"], 2) if row["avg_price"] else None,
                "total_sold": row["total_sold"],
            })

        return {"items": items, "total": total, "page": page, "page_size": page_size}
```

```python
                FeatureGateUsage.user_id == user.id,
                FeatureGateUsage.gate_key == gate_key,
                FeatureGateUsage.used_at >= today_start,
            )
        )
        used = count_result.scalar() or 0
        if used >= daily_limit:
            raise ForbiddenException(
                code=42021,
                message=f"今日搜索次数已达上限（{used}/{daily_limit}），请升级套餐或明日再试",
            )

    usage = FeatureGateUsage(
        user_id=user.id,
        gate_key=gate_key,
        detail={"action": gate_key},
    )
    db.add(usage)
    await db.flush()

    return daily_limit
```

```typescript
  const pageSize = ref(20);
  const hasSearched = ref(false);
  const searchLoading = ref(false);
  const topSoldLoading = ref(false);
  const storeGoodsLoading = ref(false);

  const filters = reactive({
    minPrice: undefined as number | undefined,
    maxPrice: undefined as number | undefined,
    minSold: undefined as number | undefined,
    sortBy: "sold_num",
  });

  const goodsResults = ref<any[]>([]);
  const storeResults = ref<any[]>([]);
  const topSoldResults = ref<any[]>([]);
  const storeGoods = ref<any[]>([]);
  const keywords = ref<{ keyword: string; item_count: number }[]>([]);
  const totalItems = ref(0);
  const usedToday = ref(0);

  const plan = computed(() => permissionStore.plan || "free");
  const dailyLimit = computed(() => DAILY_LIMITS[plan.value] ?? 5);
  const remainingSearch = computed(() => Math.max(0, dailyLimit.value - usedToday.value));
  const totalPages = computed(() => Math.ceil(totalItems.value / pageSize.value));

  const selectedStore = ref<any>(null);
  const showStoreGoods = ref(false);

  async function handleSearch() {
    if (!searchKeyword.value.trim()) return;
    hasSearched.value = true;
    searchLoading.value = true;
    currentPage.value = 1;

    try {
      if (searchMode.value === "goods") {
        const { data } = await api.post("/discovery/search", {
          keyword: searchKeyword.value,
          page: 1,
          page_size: pageSize.value,
          min_price: filters.minPrice,
          max_price: filters.maxPrice,
          min_sold: filters.minSold,
          sort_by: filters.sortBy,
        });
        if (data.code === 0) {
          goodsResults.value = data.data.items;
          totalItems.value = data.data.total;
          usedToday.value = data.data.daily_limit - (data.data.daily_limit - remainingSearch.value);
        }
      } else {
        const { data } = await api.post("/discovery/stores", {
          keyword: searchKeyword.value,
          page: 1,
          page_size: pageSize.value,
        });
        if (data.code === 0) {
          storeResults.value = data.data.items;
          totalItems.value = data.data.total;
        }
      }
      usedToday.value++;
    } catch (err: any) {
      if (err?.response?.data?.code === 42021) {
        usedToday.value = dailyLimit.value;
        ElMessage.warning(err.response.data.message);
      }
    } finally {
      searchLoading.value = false;
    }
  }

  async function handlePageChange(page: number) {
    currentPage.value = page;
    searchLoading.value = true;
    try {
      const endpoint = searchMode.value === "goods" ? "/discovery/search" : "/discovery/stores";
      const payload: any = { keyword: searchKeyword.value, page, page_size: pageSize.value };
      if (searchMode.value === "goods") {
        Object.assign(payload, {
          min_price: filters.minPrice,
          max_price: filters.maxPrice,
          min_sold: filters.minSold,
          sort_by: filters.sortBy,
        });
      }
      const { data } = await api.post(endpoint, payload);
      if (data.code === 0) {
        if (searchMode.value === "goods") goodsResults.value = data.data.items;
        else storeResults.value = data.data.items;
        totalItems.value = data.data.total;
      }
    } finally {
      searchLoading.value = false;
    }
  }

  function handleTabChange(tab: string) {
    if (tab === "top-sold" && topSoldResults.value.length === 0) fetchTopSold();
    if (tab === "keywords" && keywords.value.length === 0) fetchKeywords();
  }

  async function fetchTopSold() {
    topSoldLoading.value = true;
    try {
      const { data } = await api.get("/discovery/top-sold", { params: { page: 1, page_size: 50 } });
      if (data.code === 0) topSoldResults.value = data.data.items;
    } catch {} finally {
      topSoldLoading.value = false;
    }
  }

  async function fetchKeywords() {
    try {
      const { data } = await api.get("/discovery/keywords", { params: { page: 1, page_size: 100 } });
      if (data.code === 0) keywords.value = data.data.items;
    } catch {}
  }

  async function viewStoreGoods(store: any) {
    selectedStore.value = store;
    showStoreGoods.value = true;
    storeGoodsLoading.value = true;
    try {
      const { data } = await api.get(`/discovery/stores/${store.store_id}/goods`, {
        params: { page: 1, page_size: 50 },
      });
      if (data.code === 0) storeGoods.value = data.data.items;
    } catch {} finally {
      storeGoodsLoading.value = false;
    }
  }

  function quickSearch(keyword: string) {
    searchKeyword.value = keyword;
    searchMode.value = "goods";
    activeTab.value = "goods";
    handleSearch();
  }

  return {
    searchKeyword, searchMode, activeTab, currentPage, pageSize,
    filters, hasSearched, searchLoading, topSoldLoading, storeGoodsLoading,
    goodsResults, storeResults, topSoldResults, storeGoods, keywords,
    totalItems, totalPages, remainingSearch,
    selectedStore, showStoreGoods,
    handleSearch, handleTabChange, handlePageChange,
    viewStoreGoods, fetchKeywords, fetchTopSold, quickSearch,
  };
}
```

### 6.1 架构设计 — 只读SQLite连接池

**关键决策**：不将数据导入PostgreSQL，而是服务端直接挂载 `xhs_goods.db` 为只读SQLite数据库。

**理由**：
1. 数据已有SQLite格式，导入PG需要ETL，维护成本高
2. 35万条记录SQLite查询性能足够（<10ms）
3. 只读模式天然防止数据被篡改
4. 数据更新时只需替换db文件，无需迁移

**服务端架构**：

```

├── app/
│   ├── api/
│   │   └── discovery.py              ← 新增：商品发现API路由
│   ├── services/
│   │   └── discovery_db.py           ← 新增：只读SQLite连接池
│   └── middleware/
│       └── feature_gate.py           ← 修改：新增gate映射
├── data/
```

```python
# server/app/services/discovery_db.py
import aiosqlite
import os
from pathlib import Path
from typing import Any
from contextlib import asynccontextmanager

class DiscoveryDatabase:
    _instance = None
    _db_path: str | None = None
    _connection: aiosqlite.Connection | None = None

    def __init__(self, db_path: str):
        self._db_path = db_path

    @classmethod
    def get_instance(cls) -> "DiscoveryDatabase | None":
        return cls._instance

    @classmethod
    def initialize(cls, db_path: str) -> "DiscoveryDatabase":
        if cls._instance is None:
            cls._instance = cls(db_path)
        return cls._instance

    async def connect(self) -> None:
        if self._connection is None and self._db_path and os.path.exists(self._db_path):
            self._connection = await aiosqlite.connect(self._db_path)
            self._connection.row_factory = aiosqlite.Row
            await self._connection.execute("PRAGMA query_only = ON")
            await self._connection.execute("PRAGMA journal_mode = WAL")
            await self._connection.execute("PRAGMA cache_size = -64000")
            await self._connection.execute("PRAGMA temp_store = MEMORY")

    async def close(self) -> None:
        if self._connection:
            await self._connection.close()
            self._connection = None

    async def search_goods(
        self,
        keyword: str,
        page: int = 1,
        page_size: int = 20,
        min_price: float | None = None,
        max_price: float | None = None,
        min_sold: int | None = None,
        store_id: str | None = None,
        sort_by: str = "sold_num",
        sort_order: str = "desc",
    ) -> dict[str, Any]:
        if not self._connection:
            return {"items": [], "total": 0}

        conditions = []
        params: list[Any] = []

        if keyword:
            conditions.append("(title LIKE ? OR keyword LIKE ? OR goods_id = ?)")
            params.extend([f"%{keyword}%", f"%{keyword}%", keyword])

        if min_price is not None:
            conditions.append("deal_price >= ?")
            params.append(min_price)
        if max_price is not None:
            conditions.append("deal_price <= ?")
            params.append(max_price)
        if min_sold is not None:
            conditions.append("sold_num >= ?")
            params.append(min_sold)
        if store_id:
            conditions.append("store_id = ?")
            params.append(store_id)

        where_clause = " AND ".join(conditions) if conditions else "1=1"

        allowed_sorts = {"sold_num", "deal_price", "updated_at", "created_at"}
        sort_col = sort_by if sort_by in allowed_sorts else "sold_num"
        sort_dir = "DESC" if sort_order.lower() == "desc" else "ASC"

        count_sql = f"SELECT COUNT(*) FROM goods WHERE {where_clause}"
        async with self._connection.execute(count_sql, params) as cursor:
            total = (await cursor.fetchone())[0]

        offset = (page - 1) * page_size
        data_sql = f"""
            SELECT goods_id, title, keyword, deal_price, origin_price,
                   sold_num, store_id, store_name, image_url,
                   updated_at, first_seen, last_seen
            FROM goods
            WHERE {where_clause}
            ORDER BY {sort_col} {sort_dir}
            LIMIT ? OFFSET ?
        """
        async with self._connection.execute(data_sql, params + [page_size, offset]) as cursor:
            rows = await cursor.fetchall()

        items = []
        for row in rows:
            title_raw = row["title"] or ""
            items.append({
                "goods_id": row["goods_id"],
                "title": title_raw[:30] + ("..." if len(title_raw) > 30 else ""),
                "keyword": row["keyword"],
                "deal_price": row["deal_price"],
                "origin_price": row["origin_price"],
                "sold_num": row["sold_num"],
                "store_id": row["store_id"],
                "store_name": row["store_name"],
                "image_url": row["image_url"],
                "updated_at": row["updated_at"],
            })

        return {"items": items, "total": total, "page": page, "page_size": page_size}

    async def search_stores(
        self,
        keyword: str,
        page: int = 1,
        page_size: int = 20,
    ) -> dict[str, Any]:
        if not self._connection:
            return {"items": [], "total": 0}

        count_sql = """
            SELECT COUNT(*) FROM (
                SELECT store_id, store_name
                FROM goods
                WHERE store_name LIKE ? AND store_id IS NOT NULL AND store_id != ''
                GROUP BY store_id
            )
        """
        data_sql = """
            SELECT store_id, store_name,
                   COUNT(*) as product_count,
                   AVG(deal_price) as avg_price,
                   SUM(sold_num) as total_sold
            FROM goods
            WHERE store_name LIKE ? AND store_id IS NOT NULL AND store_id != ''
            GROUP BY store_id
            ORDER BY total_sold DESC
            LIMIT ? OFFSET ?
        """

        async with self._connection.execute(count_sql, params) as cursor:
            total = (await cursor.fetchone())[0]

        async with self._connection.execute(data_sql, params + [page_size, offset]) as cursor:

        items = []

                "store_name": row["store_name"],
                "product_count": row["product_count"],

                "total_sold": row["total_sold"],
            })

        return {"items": items, "total": total, "page": page, "page_size": page_size}

    async def get_store_goods(
        self,
        store_id: str,
        page: int = 1,
        page_size: int = 20,
    ) -> dict[str, Any]:
        if not self._connection:
            return {"items": [], "total": 0}

        count_sql = "SELECT COUNT(*) FROM goods WHERE store_id = ?"
        data_sql = """
            SELECT goods_id, title, keyword, deal_price, sold_num, image_url

            ORDER BY sold_num DESC
            LIMIT ? OFFSET ?
        """

        offset = (page - 1) * page_size
        async with self._connection.execute(data_sql, [store_id, page_size, offset]) as cursor:
            rows = await cursor.fetchall()

        items = []
        for row in rows:
            title_raw = row["title"] or ""
            items.append({
                "goods_id": row["goods_id"],
                "title": title_raw[:30] + ("..." if len(title_raw) > 30 else ""),
                "keyword": row["keyword"],
                "deal_price": row["deal_price"],
                "sold_num": row["sold_num"],
                "image_url": row["image_url"],
            })

        return {"items": items, "total": total, "page": page, "page_size": page_size}

    async def get_burst_goods(
        self,
        page: int = 1,
        page_size: int = 20,
        min_score: float = 0,
    ) -> dict[str, Any]:
        if not self._connection:
            return {"items": [], "total": 0}

        data_sql = """
            SELECT b.goods_id, b.velocity, b.acceleration, b.burst_score,
                   b.sold_1d, b.sold_3d, b.sold_7d,
                   g.title, g.deal_price, g.store_name, g.image_url
            FROM burst_scores b
            LEFT JOIN goods g ON b.goods_id = g.goods_id
            WHERE b.burst_score >= ?
            ORDER BY b.burst_score DESC
            LIMIT ? OFFSET ?
        """
        count_sql = "SELECT COUNT(*) FROM burst_scores WHERE burst_score >= ?"

        async with self._connection.execute(count_sql, [min_score]) as cursor:
            total = (await cursor.fetchone())[0]

        offset = (page - 1) * page_size
        async with self._connection.execute(data_sql, [min_score, page_size, offset]) as cursor:
            rows = await cursor.fetchall()

        items = []
        for row in rows:
            title_raw = row["title"] or ""
            items.append({
                "goods_id": row["goods_id"],
                "title": title_raw[:30] + ("..." if len(title_raw) > 30 else ""),
                "deal_price": row["deal_price"],
                "store_name": row["store_name"],
                "image_url": row["image_url"],
                "velocity": round(row["velocity"], 2),
                "acceleration": round(row["acceleration"], 2),
                "burst_score": round(row["burst_score"], 2),
                "sold_1d": row["sold_1d"],
                "sold_3d": row["sold_3d"],
                "sold_7d": row["sold_7d"],
            })

        return {"items": items, "total": total, "page": page, "page_size": page_size}

    async def get_hot_keywords(
        self,
        page: int = 1,
        page_size: int = 50,
    ) -> dict[str, Any]:
        if not self._connection:
            return {"items": [], "total": 0}

        count_sql = "SELECT COUNT(*) FROM used_keywords"
        data_sql = """
            SELECT keyword, item_count, used_at
            FROM used_keywords
            ORDER BY item_count DESC
            LIMIT ? OFFSET ?
        """
        async with self._connection.execute(count_sql) as cursor:
            total = (await cursor.fetchone())[0]

        offset = (page - 1) * page_size
        async with self._connection.execute(data_sql, [page_size, offset]) as cursor:
            rows = await cursor.fetchall()

        items = [{"keyword": row["keyword"], "item_count": row["item_count"]} for row in rows]
        return {"items": items, "total": total, "page": page, "page_size": page_size}


discovery_db = DiscoveryDatabase.__new__(DiscoveryDatabase)
```

```python
DAILY_BURST_LIMITS = {
    "free": 0,
    "pro": 10,
    "premium": 50,
    "enterprise": -1,
}


async def _check_discovery_access(user: CurrentUser, db: AsyncSession, gate_key: str) -> int:
    gate = FeatureGateMiddleware(db)
    await gate.check_gate(user, gate_key)

    plan = user.plan or "free"
    if gate_key == "gate:discovery:search":
        daily_limit = DAILY_SEARCH_LIMITS.get(plan, 0)
    elif gate_key == "gate:discovery:burst":
        daily_limit = DAILY_BURST_LIMITS.get(plan, 0)
    else:
        daily_limit = DAILY_SEARCH_LIMITS.get(plan, 0)

    if daily_limit == 0:
        from app.core.exceptions import ForbiddenException
        raise ForbiddenException(code=42020, message="当前套餐不支持商品发现功能，请升级至Pro")

    if daily_limit > 0:
        today_start = datetime.now(timezone.utc).replace(hour=0, minute=0, second=0, microsecond=0)
        from sqlalchemy import select, func
        count_result = await db.execute(
            select(func.count()).where(
                FeatureGateUsage.user_id == user.id,
                FeatureGateUsage.gate_key == gate_key,
                FeatureGateUsage.used_at >= today_start,
            )
        )
        used = count_result.scalar() or 0
        if used >= daily_limit:
            from app.core.exceptions import ForbiddenException
            raise ForbiddenException(
                code=42021,
                message=f"今日搜索次数已达上限（{used}/{daily_limit}），请升级套餐或明日再试",
            )

    usage = FeatureGateUsage(
        user_id=user.id,
        gate_key=gate_key,
        detail={"action": gate_key},
    )
    db.add(usage)
    await db.flush()

    return daily_limit


@router.post("/search")
async def search_goods(
    req: DiscoverySearchRequest,
    user: CurrentUser,
    db: AsyncSession = Depends(get_db),

async def add_to_monitor(
    req: AddToMonitorRequest,
    user: CurrentUser,
    db: AsyncSession = Depends(get_db),
):
    gate = FeatureGateMiddleware(db)
    await gate.check_gate(user, "gate:monitor:add")

    from sqlalchemy import select
    from app.models.product import Product

    existing = await db.execute(
        select(Product).where(
            Product.user_id == user.id,
            Product.platform == "xhs",
            Product.platform_product_id == req.goods_id,
        )
    )
    if existing.scalar_one_or_none():
        return {"code": 1, "message": "该商品已在监控列表中"}

    product = Product(
        user_id=user.id,
        platform="xhs",
        platform_product_id=req.goods_id,
        product_name=req.product_name or f"XHS商品 {req.goods_id[:8]}",
    )
    db.add(product)
    await db.flush()

    return {"code": 0, "data": {"product_id": str(product.id), "goods_id": req.goods_id}}
```

### 6.7 composable — useDiscoveryData.ts

```typescript
// client/src/renderer/composables/useDiscoveryData.ts
import { ref, reactive, computed } from "vue";
import api from "../utils/api";
import { usePermissionStore } from "../stores/permission";

export function useDiscoveryData() {
  const permissionStore = usePermissionStore();

  const searchKeyword = ref("");
  const searchMode = ref<"goods" | "stores">("goods");
  const activeTab = ref("goods");
  const currentPage = ref(1);
  const pageSize = ref(20);
  const hasSearched = ref(false);
  const searchLoading = ref(false);
  const burstLoading = ref(false);
  const storeGoodsLoading = ref(false);

  const filters = reactive({
    minPrice: undefined as number | undefined,
    maxPrice: undefined as number | undefined,
    minSold: undefined as number | undefined,
    sortBy: "sold_num",
  });

  const goodsResults = ref<any[]>([]);
  const storeResults = ref<any[]>([]);
  const burstResults = ref<any[]>([]);
  const storeGoods = ref<any[]>([]);
  const keywords = ref<{ keyword: string; item_count: number }[]>([]);
  const totalItems = ref(0);
  const remainingSearch = ref(30);

  const totalPages = computed(() => Math.ceil(totalItems.value / pageSize.value));

  const selectedStore = ref<any>(null);
  const showStoreGoods = ref(false);

  async function handleSearch() {
    if (!searchKeyword.value.trim()) return;
    hasSearched.value = true;
    searchLoading.value = true;
    currentPage.value = 1;

    try {
      if (searchMode.value === "goods") {
        const { data } = await api.post("/discovery/search", {
          keyword: searchKeyword.value,
          page: 1,
          page_size: pageSize.value,
          min_price: filters.minPrice,
          max_price: filters.maxPrice,
          min_sold: filters.minSold,
          sort_by: filters.sortBy,
        });
        if (data.code === 0) {
          goodsResults.value = data.data.items;
          totalItems.value = data.data.total;
        }
      } else {
        const { data } = await api.post("/discovery/stores", {
          keyword: searchKeyword.value,
          page: 1,
          page_size: pageSize.value,
        });
        if (data.code === 0) {
          storeResults.value = data.data.items;
          totalItems.value = data.data.total;
        }
      }
    } catch (err: any) {
      if (err?.response?.data?.code === 42021) {
        remainingSearch.value = 0;
      }
    } finally {
      searchLoading.value = false;
    }
  }

  async function handlePageChange(page: number) {
    currentPage.value = page;
    searchLoading.value = true;
    try {
      const endpoint = searchMode.value === "goods" ? "/discovery/search" : "/discovery/stores";
      const payload: any = { keyword: searchKeyword.value, page, page_size: pageSize.value };
      if (searchMode.value === "goods") {
        Object.assign(payload, {
          min_price: filters.minPrice,
          max_price: filters.maxPrice,
          min_sold: filters.minSold,
          sort_by: filters.sortBy,
        });
      }
      const { data } = await api.post(endpoint, payload);
      if (data.code === 0) {
        if (searchMode.value === "goods") {
          goodsResults.value = data.data.items;
        } else {
          storeResults.value = data.data.items;
        }
        totalItems.value = data.data.total;
      }
    } finally {
      searchLoading.value = false;
    }
  }

  function handleTabChange(tab: string) {
    if (tab === "burst" && burstResults.value.length === 0) {
      fetchBurstList();
    }
    if (tab === "keywords" && keywords.value.length === 0) {
      fetchKeywords();
    }
  }

  async function fetchBurstList() {
    burstLoading.value = true;
    try {
      const { data } = await api.post("/discovery/burst", { page: 1, page_size: 50 });
      if (data.code === 0) {
        burstResults.value = data.data.items;
      }
    } catch {} finally {
      burstLoading.value = false;
    }
  }

  async function fetchKeywords() {
    try {
      const { data } = await api.get("/discovery/keywords", { params: { page: 1, page_size: 100 } });
      if (data.code === 0) {
        keywords.value = data.data.items;
      }
    } catch {}
  }

  async function viewStoreGoods(store: any) {
    selectedStore.value = store;
    showStoreGoods.value = true;
    storeGoodsLoading.value = true;
    try {
      const { data } = await api.get(`/discovery/stores/${store.store_id}/goods`, {
        params: { page: 1, page_size: 50 },
      });
      if (data.code === 0) {
        storeGoods.value = data.data.items;
      }
    } catch {} finally {
      storeGoodsLoading.value = false;
    }
  }

  function quickSearch(keyword: string) {
    searchKeyword.value = keyword;
    searchMode.value = "goods";
    activeTab.value = "goods";
    handleSearch();
  }

  return {
    searchKeyword, searchMode, activeTab, currentPage, pageSize,
    filters, hasSearched, searchLoading, burstLoading, storeGoodsLoading,
    goodsResults, storeResults, burstResults, storeGoods, keywords,
    totalItems, totalPages, remainingSearch,
    selectedStore, showStoreGoods,
    handleSearch, handleTabChange, handlePageChange,
    viewStoreGoods, fetchKeywords, fetchBurstList, quickSearch,
  };
}
```

## 十一、风险与注意事项

### 11.1 双端API差异

| 场景 | Electron端 | Web-User端 |
|------|-----------|-----------|
| 商品存储 | `window.electronAPI.invoke("storage:xxx")` | `api.get/post("/products/xxx")` |
| 采集控制 | `window.electronAPI.invoke("collect:xxx")` | `api.post("/collect/xxx")` |
| 权限检查 | `window.electronAPI.invoke("permission:xxx")` | `api.get("/auth/me")` + 本地计算 |
| 实时事件 | `window.electronAPI.on("collect:result")` | WebSocket `collect:progress` |

**每个新功能必须同时实现两条路径**，参考现有 `useProductStore.fetchProducts()` 的 `if (window.electronAPI)` 分支模式。

### 11.2 IPC白名单

每新增一个IPC通道，必须同时在以下两处添加：
1. `client/src/main/ipc/handlers.ts` — 注册handler
2. `client/src/main/preload.ts` — `ALLOWED_CHANNELS` 或 `ALLOWED_LISTEN_CHANNELS`

否则会抛出 `IPC channel "xxx" is not allowed` 错误。

### 11.3 数据库迁移

服务端新增表必须：
1. 在 `server/app/models/` 新增模型
2. 在 `server/alembic/versions/` 新增迁移文件
3. 在 `server/app/api/router.py` 注册新路由

客户端新增表必须：
1. 在 `client/src/main/storage/sqlite.ts` 的 `initTables()` 中添加 CREATE TABLE
2. 在 `client/src/main/ipc/handlers.ts` 添加对应CRUD handler

### 11.4 ECharts 复用

双端都已有 ECharts 依赖（client: ^5.6.0, web-user: ^5.5.0），所有图表功能**不需要引入新图表库**。

### 11.5 Element Plus 版本

双端都使用 Element Plus（client: ^2.14.0, web-user: ^2.7.3），组件风格保持一致。

### 11.6 Feature Gate 一致性

新增的权限门控必须同时更新：
1. `shared/constants/feature_gates.py` — PLAN_LIMITS + PLAN_FEATURES_MAP
2. `client/src/renderer/stores/permission.ts` — 新增 computed 属性
3. `client/src/renderer/directives/permission.ts` — v-permission 指令自动生效
4. `server/app/middleware/feature_gate.py` — gate_key_mapping 更新
