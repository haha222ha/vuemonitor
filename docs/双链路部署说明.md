# 选品报告软件 — 双链路部署说明

两条链路分开理解：

| 链路 | 方向 | 内容 | 工具 |
|------|------|------|------|
| **A** | 你的开发机 → 云主机 | 网站、API、会员页、安装包 | `dev_deploy_gui.py` |
| **B** | 云主机 → 用户电脑 | PC 端自动检查新版本 | `productanalyzer-version.json` |

**私钥永远不要发给 AI、同事或贴到聊天。** 只需要把公钥加到服务器 `authorized_keys`。

---

## 第 0 步：清除上午的临时密钥（先做）

上午若执行过 `server-temp-deploy-key.sh`（服务器拉 GitHub 用的临时 Deploy Key），请清理：

### 云主机 SSH 执行

```bash
cd /opt/vuemonitor
bash scripts/server-destroy-temp-deploy-key.sh
```

### GitHub 网页手动操作

仓库 **Settings → Deploy keys** → 删除标题含 `vuemonitor-temp-deploy` 的公钥。

## 链路 A-1：配置「开发机 → 云主机」推送密钥

按你的要求：**在云主机生成密钥对**，私钥只留在你的 Windows，通过可视化工具配置。

### 1. 云主机生成密钥（SSH 登录后执行）

```bash
cd /opt/vuemonitor
bash scripts/server-setup-pc-upload-key.sh
```

脚本会：
- 生成 `~/.ssh/xhs365_pc_upload_ed25519`（私钥）和 `.pub`（公钥）
- 把公钥写入 `~/.ssh/authorized_keys`

### 2. Windows 下载私钥到本机（一次性，会要密码）

```powershell
mkdir $env:USERPROFILE\.ssh -Force
scp admin@47.239.181.111:~/.ssh/xhs365_pc_upload_ed25519 $env:USERPROFILE\.ssh\xhs365_pc_upload
```

> 若你用的是 `root` 用户，把 `admin` 改成 `root`。

### 3. 私钥下载成功后，回到云主机删除私钥

```bash
bash scripts/server-remove-pc-upload-private-key.sh
```

此时：**私钥只在你的电脑**，公钥仍在服务器 `authorized_keys`。

### 4. 打开可视化推送工具

```powershell
cd E:\vuemonitor
py -3.11 scripts\dev_deploy_gui.py
```

在界面填写：
- 云主机 IP：`47.239.181.111`
- SSH 用户：`admin`（或 `root`）
- 私钥路径：`C:\Users\你的用户名\.ssh\xhs365_pc_upload`
- 点 **保存配置** → **测试连接**（应显示 OK）

配置保存在 `%USERPROFILE%\.xhs365\deploy_config.json`，不会进 git。

## 链路 A-2：日常推送操作

### 场景 1 — 只更新网站 / API / 会员页（小文件，走 git）

**开发机：**

```powershell
cd E:\vuemonitor
powershell -ExecutionPolicy Bypass -File scripts\local-release.ps1
```

或在 GUI 点 **① 仅 Git Push**，再点 **② 服务器 host-update**。

**说明：** 服务器 `host-update.sh` 需要能 `git pull`。若尚未配置 GitHub Deploy Key：

```bash
cd /opt/vuemonitor
bash scripts/server-setup-github-deploy-key.sh
# 复制公钥 → GitHub Deploy keys（只读）
git remote set-url origin git@github.com-vuemonitor:haha222ha/vuemonitor.git
```

### 场景 2 — 更新用户 PC 安装包（大文件 ~277MB，走 scp）

**1. 本地构建 ProductAnalyzer：**

```powershell
cd E:\小红书监控系统所有文件相关\xhs_shelf_time
py -3.11 build_package.py
# 生成 Setup.exe 后复制为：
Copy-Item "...\Output\XHS365-Setup-xxx.exe" E:\vuemonitor\deploy\downloads\XHS365-Setup-latest.exe
```

**2. 更新版本号：**

编辑 `E:\vuemonitor\deploy\downloads\productanalyzer-version.json`：

```json
{
  "version": "2026.07.07",
  "min_version": "2026.06.01",
  "release_notes": "本次更新说明",
  "download_url": "https://www.xhs365.cn/downloads/XHS365-Setup-latest.exe"
}
```

**3. GUI 点 ④ 上传 PC 安装包**，或命令行：

```powershell
py -3.11 scripts\upload_productanalyzer_installer.py --host xhs365-deploy
```

### 场景 3 — 一次做完（代码 + 安装包）

GUI 点 **⑤ 完整发版**，或手动：local-release.ps1 → host-update → 上传安装包。

### 验证

- 网站：https://www.xhs365.cn/download
- 版本 json：https://www.xhs365.cn/downloads/productanalyzer-version.json
- API：`curl -s https://www.xhs365.cn/api/v1/public/downloads`

## 链路 B：云主机 → 用户电脑自动更新

用户 PC 上的 ProductAnalyzer **启动后会自动检查**：

```
https://www.xhs365.cn/downloads/productanalyzer-version.json
```

逻辑在客户端 `core/update_check.py` + 界面 `static/assets/app.js`：
- 远程 `version` > 本机 `version` → 顶部显示 **「发现新版本」** 横幅
- 用户点 **下载新版** → 打开 `download_url` 下载 `XHS365-Setup-latest.exe` 安装

### 你每次发 PC 新版只需 3 件事

1. 构建 `XHS365-Setup-latest.exe`
2. 把 `productanalyzer-version.json` 的 `version` 改大（日期格式如 `2026.07.07`）
3. GUI **④ 上传安装包** 到服务器

用户下次打开软件即可看到更新提示（无需你远程操作用户电脑）。

### 强制最低版本（可选）

把 `min_version` 设为更高版本后，旧版用户会被提示升级（客户端按版本号比较）。

## 密钥对照表

| 用途 | 在哪生成 | 公钥加到哪 | 私钥在哪 |
|------|----------|-----------|----------|
| 开发机 scp 上传安装包 | **云主机** `server-setup-pc-upload-key.sh` | 服务器 `authorized_keys` | **仅你的 Windows** |
| 服务器 git pull | 云主机 `server-setup-github-deploy-key.sh` | GitHub Deploy keys | **仅云主机** |
| ~~上午临时 key~~ | 已废弃 | GitHub 手动删 | `server-destroy-temp-deploy-key.sh` 清掉 |

## 常见问题

**Q: `ssh` 测试要密码？**  
A: 公钥未写入 `authorized_keys`，或私钥路径填错。重新执行 `server-setup-pc-upload-key.sh`。

**Q: host-update 报 git 权限？**  
A: 配置 GitHub Deploy Key（`server-setup-github-deploy-key.sh`）。

**Q: 用户看不到更新？**  
A: 检查 `productanalyzer-version.json` 的 `version` 是否大于用户本机版本；浏览器打开 json 确认已更新。

**Q: 能否把私钥给 Cursor？**  
A: **不能。** 只需告诉 AI「SSH 已配好，Host=xhs365-deploy」即可。
