## 零、核心认知升级

### V1 vs V2 的本质区别

| 维度 | V1（当前） | V2（目标） |
|------|-----------|-----------|
| **产品形态** | 卖PDF/报告/文件 | 卖数据库访问权限 |
| **用户心智** | "买个AI报告看看" | "订阅一个AI情报系统" |
| **收入模型** | 一次性交易 | 订阅制持续付费 |
| **核心资产** | 内容生成能力 | 趋势历史数据库 |

| **交付方式** | 本地文件系统 | Notion中台+Super.so会员站 |
| **SKU数量** | 每个选题一个SKU（爆炸） | 5个权限等级（收敛） |

```
从"AI帮我写一份副业报告"

"我订阅了一个AI趋势情报决策系统"
```

### 2.3 SKU策略：从产品爆炸到权限收敛

**V1问题**：每个选题=一个SKU，10个选题=10个SKU，100个选题=100个SKU，不可持续。

**V2方案**：SKU = 权限等级 × 时间周期

#### 小红书店铺SKU（前台仅3个，极度收敛）

| SKU | 价格 | 定位 | 对应后台等级 |
|-----|------|------|------------|
| 一周精选（7天体验） | ¥9.9 | 降低决策门槛 | Free→Basic 过渡 |
| 月度会员 | ¥49/月 | 核心盈利 | Basic+PRO |
| 年度会员 | ¥299/年 | 利润核心 | PRO+Elite |

**总共3个SKU**，无论后台有多少选题，前台永远只有这3种购买选项。

**后台会员权限映射（5级 → 3产品）**：

| 产品 | 对应后台权限 | 说明 |
|------|------------|------|
| 一周精选 ¥9.9 | Free增强版 | 7天临时访问Basic级别内容 |
| 月度会员 ¥49/月 | Basic + PRO | 每日趋势+每周报告+数据库访问 |
| 年度会员 ¥299/年 | PRO + Elite | 全量数据库+月度深度报告+历史回溯 |

**为什么从8-9个SKU收敛到3个？**
- 小红书用户价格敏感度高，¥50以下决策最快
- 选择越少转化越高（经典消费心理学）
- 年会员锚定效应：¥299/年 vs ¥49×12=¥588 → "一年省¥289"
- 一周精选¥9.9作为"试用钩子"，体验后可抵扣月会员

## 三、Notion中台技术方案

### 3.1 推荐方案：Notion + Super.so

```
Notion（数据库引擎）
    ↓ Notion API同步
Super.so（网站化 + 权限层）
    ↓
会员网站（yourdomain.com）
```

**为什么用Super.so而不是纯Notion分享？**

| 方案 | 优点 | 缺点 |
|------|------|------|
| 纯Notion分享 | 零成本、即时可用 | 无法做权限分级、无法自定义域名、无法商业化 |
| Notion+Super.so | 网站化、权限控制、自定义域名、SEO | 月费$29起 |

**初期方案**：直接使用Notion的Share to web功能，手动管理不同页面的分享链接，根据会员等级发送对应链接。零额外成本启动。

### 3.2 权限映射方案

```
Notion页面结构：
/
├── /free          ← 任何人可访问（公开链接）
├── /basic         ← Basic会员可见（独立分享链接）
├── /pro           ← PRO会员可见（独立分享链接）
├── /elite         ← Elite会员可见（独立分享链接）
└── /enterprise    ← 企业版可见（独立分享链接）
```

**初期人工管理**：不同等级用户获得不同Notion分享链接。用户付费后，手动发送对应链接。

**中期自动化**：Super.so配置权限组 → 用户注册登录 → 自动获得对应权限。

### 3.3 数据同步流水线

```
每日定时任务（Python脚本）：
│
├── 1. 读取 database/*.json
├── 2. 调用Notion API → 更新趋势数据库
├── 3. 调用Notion API → 更新Dashboard
├── 4. 调用Notion API → 更新风险预警
├── 5. 检查更新 → 触发周报/月报生成
└── 6. 日志记录 + 异常告警
```

关键脚本模板：

```python
# notion_sync.py — 每日数据同步脚本
import json, os
from notion_client import Client

NOTION_TOKEN = os.environ["NOTION_API_KEY"]
DATABASE_IDS = {
    "trend": "your_trend_db_id",
    "opportunity": "your_opportunity_db_id",
    "risk": "your_risk_db_id",
    "dashboard": "your_dashboard_id",
}

def sync_trend_db(notion, data_file):
    """同步趋势数据到Notion"""
    with open(data_file, 'r', encoding='utf-8') as f:
        trends = json.load(f)
    for trend in trends:
        notion.pages.create(
            parent={"database_id": DATABASE_IDS["trend"]},
            properties={
                "title": {"title": [{"text": {"content": trend["title"]}}]},
                "opportunity_score": {"number": trend["score"]},
                "lifecycle": {"select": {"name": trend["lifecycle"]}},
                "risk_level": {"select": {"name": trend["risk_level"]}},
            }
        )

if __name__ == "__main__":
    notion = Client(auth=NOTION_TOKEN)
    sync_trend_db(notion, "商业情报中转站/database/trend_db.json")
```

## 四、小红书变现链路升级

### 4.1 内容策略升级：从"卖报告"到"卖情报感知"

**V1模式（当前）**：
```
小红书笔记 → 引导购买PDF报告
```

**V2模式（升级）**：
```
小红书笔记 → 建立"趋势情报权威感" → 引导订阅会员
```

### 4.2 笔记内容转型

**禁止出现的文案**：
- "买我的报告"
- "我有份PDF"
- "付费获取"
- "评论区扣1"

**必须营造的感知**：
- "我是一个能持续监控互联网趋势的系统"
- "我每天都能发现新的副业机会"
- "我预判了XX赛道的变化"

**正确的内容结构模板**：

```
标题：为什么最近XX副业突然爆了？

开头：
最近我的AI监控系统发现了一个明显变化：

正文（三段式）：
1. 用户端的变化（搜索量、焦虑词频、关注点迁移）
2. 平台端的变化（流量倾斜、新功能、规则调整）
3. 机会窗口（为什么现在切入、窗口期预估、普通人注意事项）

结尾：
这可能是未来3个月的重要趋势。
我每天持续监控这些变化，下期讲XX。

——————
（数据来源：AI趋势监控系统）
```

**关键原则**：笔记本身不推销，而是在结尾自然带出"我在持续监控"，让感兴趣的用户主动问"怎么获取"。

### 4.3 小红书商品页设计

**商品名称**：`AI趋势决策情报会员`（不要说PDF/报告/合集）

**商品卖点**（7条）：
1. 每日趋势更新（不是一次性报告）
2. AI副业机会发现（不是人工整理）
3. 小红书爆款方向预测
4. 用户需求变化监控
5. 平台流量变化追踪
6. 风险预警（什么时候该撤退）
7. 趋势历史数据库（可回溯验证）

**商品图风格**：Dashboard截图风格，情报系统感，深色主题，数据可视化。

| 内容生产跟不上 | 会员觉得更新慢 | 每日至少更新3条趋势+1个机会+1个风险 |

## 九、关键决策点

### 9.1 需要你明确决定的5个问题

1. **定价**：Basic月费定39还是59？PRO定99还是199？
2. **域名**：是否需要独立域名会员站（Super.so $29/月），还是先用Notion免费分享？
3. **支付**：先用人工（闲鱼/微信），还是直接上Stripe自动化？
4. **启动时间**：P0基础设施什么时候开始搭建？
5. **内容储备**：上线前需要储备多少天的内容存量？（建议至少7天）

### 9.2 我的建议

| 问题 | 建议 | 理由 |
|------|------|------|
| 定价 | Basic ¥49, PRO ¥149 | 心理锚点：PRO是Basic的3倍，但不超200 |
| 域名 | 初期用Notion免费分享 | 付费用户<20人时不值得$29/月 |
| 支付 | 初期人工，用户>20后自动化 | 降低启动复杂度 |
| 启动 | 本周内搭建Notion | 越快越好，数据资产每天都在积累 |
| 内容储备 | 上线前储备14天 | 给用户足够的"持续更新"体感 |
