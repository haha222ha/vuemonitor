# AI互联网信息量化系统 - 远程同步指南

> 本文档供 AI 助手阅读，理解系统架构后即可自动生成情报数据并同步到服务器。

---

## 一、系统概述

本系统将本地 AI 产出的商业情报数据同步到远程服务器 `https://intel.xhs365.cn`，供付费会员在前端查看。

**核心流程**：AI 产出数据 → 写入 JSON 文件 → 执行同步脚本 → 数据推送到服务器

## 三、同步配置

### 3.1 配置文件：remote_sync/sync_config.json

```json
{
  "remote_host": "https://intel.xhs365.cn",
  "api_token": "REDACTED_INTEL_SYNC_KEY",
  "sync_options": {
    "batch_size": 50,
    "retry_count": 3,
    "retry_delay_seconds": 5,
    "timeout_seconds": 60,
    "request_delay_ms": 200
  },
  "targets": {
    "trends": true,
    "signals": true,
    "opportunities": true,
    "risks": true,
    "emotions": true,
    "xhs_topics": true
  }
}
```

### 3.2 关键参数说明

| 参数 | 值 | 说明 |
|------|-----|------|
| remote_host | `https://intel.xhs365.cn` | 服务器地址 |
| api_token | `REDACTED_INTEL_SYNC_KEY` | 同步API密钥（Bearer Token） |
| batch_size | 50 | 每批最大推送条数 |

### 3.3 API认证方式

所有同步请求在 HTTP Header 中携带：
```
Authorization: Bearer {api_token}
```

## 四、数据格式与字段映射

### 4.1 趋势数据 (trends)

**数据源**：`商业情报中转站/database/trend_db.json` → `trends` 数组

**同步端点**：`POST /api/v1/intel/sync/trends`

**字段映射**：

| 本地字段 | 服务器字段 | 类型 | 必填 | 说明 |
|----------|-----------|------|------|------|
| trend_name | title | String(200) | ✅ | 趋势标题（唯一键） |
| category | category | String(50) | ✅ | 分类 |
| platform | platform | String(50) | ✅ | 平台名称 |
| direction | direction | String(10) | ❌ | 方向：快速上升/上升/稳定/下降 |
| lifecycle | lifecycle | String(20) | ❌ | 生命周期：早期/爆发期/成熟期/衰退期 |
| evidence | evidence | Text | ❌ | 证据描述 |
| actionable_insight | actionable_insight | Text | ❌ | 可执行洞察 |
| affected_opportunities | affected_opportunities | JSONB | ❌ | 关联机会列表 |
| risk_note | risk_note | Text | ❌ | 风险备注 |
| peak_expected | peak_expected | DateTime | ❌ | 预计峰值时间（格式：2026-08-01） |

**自动处理**：`id`, `first_observed` 等未映射字段自动存入 `source_data`

**示例**：
```json
{
  "trend_name": "AI工具教程内容爆发",
  "category": "AI副业",
  "platform": "小红书",
  "direction": "快速上升",
  "lifecycle": "早期",
  "evidence": "AI工具相关笔记搜索量同比增长120%",
  "actionable_insight": "AI工具对比/测评/教程类内容有6-12周红利窗口期",
  "affected_opportunities": ["AI副业变现", "AI代运营"],
  "risk_note": "内容同质化速度加快",
  "peak_expected": "2026-08-01"
}
```

## 五、同步操作

### 5.1 一键同步

**Windows**：双击 `remote_sync/sync.bat` 或：
```bash
cd remote_sync && python full_sync.py
```

**Mac/Linux**：
```bash
cd remote_sync && bash sync.sh
```

### 5.2 高级用法

```bash
# 先验证不实际推送
python full_sync.py --dry-run

# 只同步某个目标
python full_sync.py --target trends

# 跳过健康检查
python full_sync.py --no-health-check

# 详细日志
python full_sync.py --verbose
```

### 5.3 同步行为说明

- **增量同步**：已存在的数据（按唯一键匹配）会更新内容，不会重复创建
- **幂等性**：相同 batch_id 不会重复处理
- **多余字段**：本地JSON中服务器模型不存在的字段，自动存入 `source_data` JSONB字段
- **日期转换**：字符串日期（如 `"2026-08-01"`）自动转为 DateTime

## 六、AI助手操作指南

### 当你需要新增情报数据时：

1. **确定数据类型**（趋势/机会/风险/情绪/选题）
2. **按上述格式写入对应JSON文件**
3. **执行同步**：`cd remote_sync && python full_sync.py`

### 当你需要更新已有数据时：

1. **修改JSON文件中对应条目**
2. **执行同步**（自动识别为更新）

### 当你在新电脑上工作时：

1. **复制整个 `AI互联网信息量化` 文件夹**
2. **安装依赖**：`pip install httpx`
3. **执行同步**：`cd remote_sync && python full_sync.py`

## 八、P1：定时同步与生产店铺链接

### 8.1 生产配置（仓库根目录）

编辑 `vuemonitor/config/intel_production.json`：

- `xhs_shop_url`：小红书店铺链接（续费 Banner 使用）
- `sync_schedule`：Windows 计划任务时间，默认 `08:00`、`20:00`
- `report_upload`：定时任务是否自动上传最新选题 `html/` 报告

### 8.2 构建情报前端（写入店铺链接）

```powershell
cd D:\vuemonitor
powershell -ExecutionPolicy Bypass -File scripts\build-web-intel.ps1
```

会生成 `web-intel/.env.production` 并构建 `dist/`。服务器部署时 `scripts/deploy.ps1` 也会读取同一配置。

### 8.3 注册 Windows 定时同步

```powershell
cd "D:\vuemonitor\AI互联网信息量化\remote_sync"
powershell -ExecutionPolicy Bypass -File register_windows_tasks.ps1
```

手动试跑：

```powershell
powershell -ExecutionPolicy Bypass -File scheduled_sync.ps1
```

等价于 `python full_sync.py --scheduled`（全量同步 + 可选报告上传）。

移除计划任务：

```powershell
powershell -ExecutionPolicy Bypass -File register_windows_tasks.ps1 -Unregister
```
